# 自主学習アプリ(旧:さんすうノート)

算数(小3〜6)・数学(中1〜高3)・国語・英語を、コツコツ自主学習できるブラウザ問題集アプリ。
URLは従来どおり https://totty1007.github.io/sansu-note/

## 教科と内容
| 教科 | レベル | 内容 |
|---|---|---|
| さんすう | 3〜6年 | 筆算・図形・角度・分数・割合など(SVG図解つき) |
| すうがく | 中1〜中3、数Ⅰ・A、数Ⅱ・B、数Ⅲ | 計算・方程式・関数・図形・確率・三角関数・微積分・数列・複素数平面など(毎回数値が変わる自動生成) |
| こくご | 小学・中学・高校受験 | 漢字の読み・書き取り、古文単語、古文文法(中学は古文の基礎) |
| えいご | 小学・中学・高校受験 | 英単語(英→日/日→英)、英熟語、英文法(4択)、長文読解 |

- 暗記系・文法系は重要度(◎最重要／○重要／△標準)付きの厳選リスト。「◎○重要」「◎最重要のみ」に絞り込み可
- まちがえた問題は「🔁 ふくしゅう」として優先的に再出題(ユーザーごとに記録)
- 正解率・ポイント・ごほうびの猫はブラウザのlocalStorageに保存(端末ローカルのみ)
- スマホでは「ホーム画面に追加」でアプリのように起動可能(PWA対応)

すべてクライアントサイドの静的HTMLのみで動作し、サーバー側の処理や外部送信は一切行っていません。

## 構成
- `index.html` … エンジン(出題・4択・成績・ごほうび)と算数の問題生成
- `data/*.js` … 問題データ
  - 国語: `kanji-e/j/h.js`、`kobun-j/h.js`、`kobun-bunpo.js`
  - 英語: `eigo-tango-e/j/h.js`、`eigo-jukugo-j/h.js`、`eigo-bunpo-j/h.js`、`eigo-read-j/h.js`
  - 数学: `sugaku-j1/j2/j3/h1/h2/h3.js`(`registerMath`で問題生成関数を登録)

## データの形式
カード式デッキ(`registerDeck`)。項目の `t` は重要度(`S`/`A`/`B`)。
- 意味系(古文単語・英単語・英熟語): `{q:'見出し', a:'意味', t:'S', n:'ワンポイント', w:[誤答3つ(任意)]}`、modes は `fwd`(問→答)/`rev`(答→問)
- 漢字: `{q:'憂鬱', a:'ゆううつ', s:'{憂鬱|ゆううつ}な気分', wr:[誤読3], wk:[誤表記3], t:'A', n:'意味'}`、modes は `yomi`/`kaki`
- 4択問題(文法): `{q:'問題文', a:'正解', w:[誤答3つ], t:'A', n:'解説'}`、mode は `qa`
- 長文読解: デッキに `passages:{p1:'本文'}`、項目に `p:'p1'`、mode は `read`

数学は `registerMath('s_j1', [{id, name, gen(){...}}])`。`gen()` は数値答え(`kind:'text'`)か、式を答えにできる `mkCard(問題HTML, 正解, [誤答...], 解説)` を返す。

データを足したら `sw.js` の `CACHE_NAME` のバージョンを上げる。
新しいデータファイルを作った場合は `index.html` の `<script src>` と `sw.js` の `CORE_FILES` にも追加する(1つでも404だとオフライン用キャッシュの登録が失敗する)。

## 内容について
厳選リストや問題は市販の単語帳・問題集を写したものではなく、自作。
読み・意味・答え・誤答は別のエージェントによる全件点検を経ているが、人の目による確認は入っていない。誤りを見つけたら該当ファイルの1行(数学は生成関数)を直せばよい。

# さんすうノート(さんすう／こくご／えいご)

算数(3〜6年生)に加えて、国語(漢字・古文単語)と英語(単語・熟語)を、
コツコツ練習できるブラウザ問題集アプリ。

- 教科タブ(さんすう／こくご／えいご)と、学年・レベルタブ(小学／中学／高校・受験)、単元チップで切り替え
- 筆算・図形・角度などはSVG図解つきで出題(算数)
- 国語:漢字の読み・書き取り(小学〜高校)、古文単語(中学入門・高校受験)
- 英語:英単語(英→日・日→英)、英熟語(中学・高校受験)。小学は単語のみ
- 暗記系は重要度(◎最重要／○重要／△標準)付きの厳選リスト。「重要のみ」「最重要のみ」に絞り込み可
- まちがえた問題は「🔁 ふくしゅう」として優先的に再出題(ユーザーごとに記録)
- 正解率・ポイント・ごほうびの猫はブラウザのlocalStorageに保存(端末ローカルのみ)
- スマホでは「ホーム画面に追加」でアプリのように起動可能(PWA対応)

すべてクライアントサイドの静的HTMLのみで動作し、サーバー側の処理や
外部送信は一切行っていません。

## 構成

- `index.html` … エンジン(出題・4択・成績・ごほうび)と算数の問題生成
- `data/*.js` … 国語・英語の問題データ。`registerDeck({...})` で登録
  - `kanji-e/j/h.js`(漢字)、`kobun-j/h.js`(古文単語)
  - `eigo-tango-e/j/h.js`(英単語)、`eigo-jukugo-j/h.js`(英熟語)

## 問題データの追加・修正

各デッキは次の形式。項目の `t` は重要度(`S`/`A`/`B`)。

- 意味系(古文単語・英単語・英熟語): `{q:'見出し', a:'意味', t:'S', n:'ワンポイント', w:[誤答3つ(任意)]}`
- 漢字: `{q:'憂鬱', a:'ゆううつ', s:'{憂鬱|ゆううつ}な気分', wr:[誤読3], wk:[誤表記3], t:'A', n:'意味'}`

データを足したら `sw.js` の `CACHE_NAME` のバージョンを上げる。
新しいデータファイルを作った場合は `index.html` の `<script src>` と `sw.js` の `CORE_FILES` にも追加する。
誤答を指定しない項目は、同じデッキの他の語の答えから自動で選ばれる。

## 内容について

厳選リストは市販の単語帳・問題集を写したものではなく、頻出度をもとに自作したもの。
読み・意味・誤答は監査済みだが、誤りを見つけたら該当ファイルの1行を直せばよい。
